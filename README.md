# Zalo中文增强模块（com.zalocn）

> 把 Zalo 界面从**越南语 / 英文**翻译成**简体中文**的 Xposed 模块。
> 收到的消息实时翻成中文，自己打中文点一下就翻成越南语发出去。

## 🎉 v3.0.0 重磅更新：消息也能翻了

这一版模块从「界面汉化工具」变成了「在越南用 Zalo 跟当地人沟通的中文助手」：

- **收到的消息实时翻译**：越南语自动翻成中文，原文在上、译文在下，11 种目标语言可选
- **输入框「译」按钮**：输中文点一下，翻成越南语（或你选的语言）填回输入框，检查完自己点发送，不自动发
- **自定义大模型 API**：OpenAI 兼容接口，免密钥的公开 API 也能用（比如 bilibili 公开翻译接口）
- **模板系统**：每个大模型独立保存自己的 API 数据，拉下切换就换生效模型
- **免费引擎**：Google / Google 备用 / Bing / MyMemory，免密钥，选上直接用
- **测试当前 API**：点一下验证，成功显示「当前api配置能正常使用」，失败直接显示原因（连接失败 / API 地址有误 / 找不到模型 / API 错误）
- **设置页改版**：分区卡片，全部自动保存，不用再点保存按钮

界面汉化还是离线词表；消息翻译走你自己的 API 或免费引擎，需要联网。

## 功能

- **12600+ 条翻译**，覆盖设置、隐私、聊天、群组、动态、日历、通知、我的文档、钱包等页面
- **越南语 → 保持越南语，英文 → 中文**：自动跟随 Zalo 内建的语言开关，不会把越南语界面也翻成中文
- **服务器下发的文本也能翻**（ZInstant 动态 UI，如安全检查页、小程序分类）
- **纯 UI 翻译**：只替换屏幕显示文字，不改 Zalo 本体、不碰网络请求与账号数据，界面汉化全在本地离线可用

## 支持版本

- 实测 **Zalo 26.11.01**，Android 16 真机验证通过
- hook 的是系统层方法，不依赖具体版本号，26.x 新老版本大概率通用
- 系统要求：**Android 8.1+**，需 Root + **LSPosed / Vector**

## 安装

1. 到本页右侧 **Releases** 下载最新 APK（包名 `com.zalocn`，应用名「Zalo中文增强模块」，文件 `Zalocn-E.apk`）
   —— 或直接去[源码仓库 Releases](https://github.com/guoxpeng/zalo-cn/releases) 拿更新的版本
2. 打开 LSPosed / Vector Manager → 启用模块 → **作用域勾选 Zalo（`com.zing.zalo`）**
   （这步漏了不生效）
3. **强制停止 Zalo 再重开**（模块只在进程新建时注入）

> 两个仓库发的 APK 是**同一个构建、同一个签名**，可以互相覆盖安装，也可以直接覆盖旧版本升级。

PC 端（Windows）的汉化+翻译一键安装器见源码仓库的 `pc/` 目录。

## 常见问题

**装了没效果？**
九成是作用域没勾 Zalo，或改完没强制停止 Zalo。重启手机基本能解决。

**消息没出译文？**
先看设置页（桌面图标「Zalo中文增强模块设置」）里的翻译引擎配好了没有，点「测试当前 API」，它会直接告诉你原因。免费引擎不用填密钥，选上就能用。

**切到越南语后界面还有中文？**
不应出现。模块检测到越南语会整体停止翻译。

**会封号吗？**
风险极低但不是零 —— 模块只改显示文本，不发修改请求、不碰服务器通信。介意就用小号先试几天。

**有页面还是英文？**
去[源码仓库](https://github.com/guoxpeng/zalo-cn/issues)提 Issue，附页面截图，针对性补翻译。

## 已知限制

- 钱包的 Activity（交易记录）、Card（卡）页面是 Zalo 服务器下发的 H5 网页，仍为英文
- 极少数写死在自定义控件里的文本（如聊天列表里的「My Documents」会话名）可能漏翻
