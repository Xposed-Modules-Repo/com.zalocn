## 🎉 v3.0.0：消息也能翻了，不只是界面汉化

以前这个模块只做一件事：把 Zalo 界面翻成中文。现在它能帮你跟越南人聊天：

- **对方发越南语，你看到的就是中文**：消息一来自动翻，原文在上面、译文在下面，不用来回复制
- **你打中文，点一下「译」，就变成越南语发过去**：输入框边上有个「译」按钮，翻好先填回输入框，你检查一眼再点发送，不会帮你乱发
- **想翻成别的语言也行**：不只中文，英、泰、老、柬、缅、马来、印尼、日、韩、越，11 种语言随便选
- **不用填账号密码也能翻**：内置免费翻译（Google 等），装好选上就能用
- **想用自己的大模型也行**：填个接口地址就能接自己的模型，免密钥的公开接口（比如 bilibili 公开翻译接口）也能用
- **配错了会直接告诉你**：点一下「测试当前 API」，能用就说能用，不能用就说清原因（连不上 / 地址错了 / 找不到模型 / 接口报错）
- **设置一改就保存**：不用再点保存按钮

> ⚠️ **升级注意：v3.0.0 是重大版本更新，换了签名，老版本不能直接覆盖安装。**
> 如果你现在装的是 **2.6.1 及更早版本**，必须**先卸载老版本，再装 v3.0.0**，直接点安装会报“与现有软件存在冲突”。
> 卸载会清空已保存的配置（大模型地址、密钥、模板、提示词），装好后要重新填一遍；LSPosed 里也要重新勾选 Zalo 作用域。
> 从 2.7.0 测试版升上来的不受影响，签名相同，直接覆盖安装就行。

## 还能做什么

- **界面全是中文**：12600 多条翻译，设置、聊天、群组、钱包、日历、通知，基本都翻了
- **服务器下发的页面也能翻**：比如安全检查页、小程序分类这些动态页面
- **只改显示，不动账号**：不改 Zalo 本体、不碰网络请求，界面汉化在手机本地离线就能用；消息翻译要联网，走的是你自己配的接口或免费翻译

## 能用在哪个版本

- 实测 **Zalo 26.11.01**，Android 16 真机验证通过
- 26.x 新老版本大概率都通用
- 需要 **Android 8.1 以上**，手机已 Root，装了 **LSPosed / Vector**

## 三步装好

1. 到本页右侧 **Releases** 下载最新 APK（包名 `com.zalocn`，应用名「Zalo中文增强模块」，文件 `Zalocn-E.apk`）
   —— 或直接去[主仓库 Releases](https://github.com/guoxpeng/zalo-cn/releases) 拿更新的版本
2. 打开 LSPosed / Vector Manager → 启用模块 → **作用域勾选 Zalo（`com.zing.zalo`）**（这步漏了不生效）
3. **强制停止 Zalo 再重开**（模块只在进程新建时注入）

> 两个仓库发的 v3.0.0 是**同一个构建、同一个签名**，可以互相覆盖安装；但从 2.6.1 及更早版本升上来，必须先卸载老版本再装，不能直接覆盖（见上面 v3.0.0 一节的升级注意）。

PC 端（Windows）的汉化+翻译一键安装器，见主仓库的 `pc/` 目录。

## 版本号怎么读

本仓库的 Release 标签是 **`<versionCode>-<versionName>`**，比如 `33-3.0.0`：

- 手机上的模块管理器靠 `versionCode` 判断要不要提示你更新
- 标签只在维护者同步主仓库时才新增，所以**这里没新标签 ≠ 项目停更**，最新进度请看[主仓库的提交记录](https://github.com/guoxpeng/zalo-cn/commits/main)

## 常见问题

**装了没效果？**
九成是作用域没勾 Zalo，或改完没强制停止 Zalo。重启手机基本能解决。

**消息没出译文？**
先看设置页（桌面图标「Zalo中文增强模块设置」）里的翻译配好了没有，点「测试当前 API」，它会直接告诉你原因。免费翻译不用填密钥，选上就能用。

**切到越南语后界面还有中文？**
不应出现。模块检测到越南语会整体停止翻译。

**会封号吗？**
风险极低但不是零 —— 模块只改显示文本，不发修改请求、不碰服务器通信。介意就用小号先试几天。

**有页面还是英文？**
去[主仓库](https://github.com/guoxpeng/zalo-cn/issues)提 Issue，附页面截图，针对性补翻译。

## 已知限制

- 钱包的交易记录、卡页面是 Zalo 服务器下发的网页，仍为英文
- 极少数写死在自定义控件里的文本（如聊天列表里的「My Documents」会话名）可能漏翻
